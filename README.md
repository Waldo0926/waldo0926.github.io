# waldo0926.github.io

My blog, built by GitHub Pages with Jekyll and the minima theme. Posts are in `_posts/`, one English and one Chinese file per post.

我的博客，用 GitHub Pages 自带的 Jekyll 和 minima 主题生成。文章在 `_posts/`，每篇有英文和中文两个文件。

Preview locally / 本地预览：

```sh
gem install jekyll minima jekyll-feed jekyll-seo-tag
jekyll serve
```
