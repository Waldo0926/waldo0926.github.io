验收[国内只读版]({% post_url 2026-11-27-hub-readonly-mirror-zh %})桌面端页面的时候，盯着整页截图看出了好几处以前海外站也一直存在的布局和文案问题。这些问题不影响功能，所以拖了好几周都没动，但截成整图一看就特别扎眼

## 四个顺手修掉的布局与文案问题

1. **页脚单列向下凸出**：页脚里的 `功能导航` 8 个链接排成了一竖列，而旁边的官方来源和系统入口三列各自只有 3 到 4 行，导致页脚右边大片留白。把 `功能导航` 改成两列网格（把 `找选修课` 和 `学费查询` 也补进去，排成 2 列 × 5 行），同时去掉首页最后一个区块底部叠加的约 160 px 空白，整个页脚立刻齐平
2. **首页右下角大片空白**：之前重要日期只列 4 条，下面的 `常用系统` 是一堆小胶囊标签，卡片下半截空了一半。把首页重要日期改成默认展示 6 条，下面的标题改成 `常用系统入口`，每个入口从胶囊改成 2 列带一行用途说明的小卡片（比如 `Moodle · 课件与作业`、`WES · 选课与成绩`、`Allocate+ · 排课表选班`），把留白换成了对新生真正有用的信息
3. **顶栏命名与优先级**：新生常分不清 `课程` 和 `专业与学位` 的区别，`给家长看` 又是灰色小字夹在搜索框旁边，很容易被忽略。把中文文案统一改成 `课程查询`、`学费查询`、`家长入口`；顶栏把 `官方指南` 放第一项，高频的 `WAM/GPA` 和 `学费查询` 提到一级导航，`选课工具` 下拉只放选课三件套（`选课规划`、`先修图`、`找选修课`），`家长入口` 做成浅蓝胶囊放进主导航，一眼就能看到
4. **长指南吸顶目录和课程页收尾**：把 `/guides/[slug]` 原本占在正文上面的章节大纲移到右侧栏吸顶，长政策翻到底也能跳章节；`/units/[code]` 底部加了一张简短的继续规划卡片，看完课程可以直接跳先修图、选课规划或年份对比

## PR #301 合并前，Playwright 拦下了两件事

本地 `vitest` 单测和 `nuxi typecheck` 全过之后我提了 PR #301，结果 GitHub Actions 的 Playwright 浏览器测试挂了 2 条用例（桌面和手机各跑一次，76 个里挂了 4 个）：

- **`e2e/tests/pwa.spec.ts:32`**：断言中文版 `/manifest.webmanifest` 里的快捷方式包含 `课程`。因为 PWA manifest 直接读了 `nav.units`，把文案改成 `课程查询` 后，manifest 快捷方式也跟着变了——提醒了我改一个 i18n 键会影响到页面可见导航以外的地方
- **`e2e/tests/units.spec.ts:57`**：用 `page.getByRole('link', { name: /比较年份|Compare years/ })` 定位链接时没加 `.first()`。我们在课程页底部加了规划卡片后，页面上出现了第二个 `比较年份变化` 链接，直接触发了 Playwright strict mode 报错

两处都是改一行的测试更新，CI 提前拦下来也避免了线上回归

## 上线后一眼看出的 CSS Grid 拉伸坑

PR #301 合并部署到海外站后，一刷新首页就发现一个很丑的问题：左栏 8 张入口卡片被拉成了细长条，底下空出一大截灰色

把左右两栏放一起看，原因一下子就清楚了：

- `.hero` 设了 `align-items: stretch`，`.tools` 又设了 `flex: 1 1 auto; grid-auto-rows: 1fr;`
- 右栏把重要日期加到 6 条、常用系统改成 2 列卡片后，整体增高了大约 220 px
- 国内版左栏是 **3×3 九宫格（3 行）**，每张卡片分摊下来大约 175 px 高，接近正方形，看着很舒服
- 海外版左栏还是旧的 **4×2（只有 2 行）**，而且漏了 `找选修课`（`/electives`），结果 CSS Grid 把这两行强行撑到了每行约 270 px，再加上 `align-content: start` 把图标和文字顶在最上面，底下就空出了大片灰色

PR #303 的修法比硬写 `max-height` 更干净：把海外和国内统一成 **3×3 九宫格**，给海外补上 `找选修课`（第 9 格海外留 `社区`，国内放 `马莫百科`），卡片内部改成 `align-content: center` 垂直居中，同时把右栏 `.hero-side` 设为 `grid-template-rows: 1fr auto`，不管切到马来西亚还是澳大利亚校区，常用系统卡片都不会被拉变形

顺着同一批截图，我还把公众号模块的标题从读起来有点别扭的 `马莫同学写的公众号` 改成了 `马莫学生运营的公众号`——这张卡片同时介绍了文章、后台自动回复机器人和关注二维码，“运营的公众号”比“写的公众号”贴切得多
