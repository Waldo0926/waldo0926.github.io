About

I’m Shuoxun Wen (温硕勋), studying Computer Science (Algorithms and Software) at Monash University.

A lot of what I build is for Monash students, but I also work on algorithms, data and Linux/network infrastructure. For the complete public project archive, see the separate projects page. I run my public sites myself: a VPS with Docker, nginx, automated deploys and a public status page. This blog is where I write down how those projects work and what went wrong along the way.

Projects

  • Monash Hub: unit and degree information, a course map, a WAM calculator, Malaysia tuition fees, key dates and the official student guides, in English and Chinese. (code)
  • SecureView: a secure file sharing platform where the browser encrypts every file. Our final year project, with work on testing, deployment and documentation. (code)
  • Monash Study Kit: 1.16.0 is on PyPI. Export Moodle Pages, Books, assignment descriptions and attachments, Ed Lessons and course-linked Google files as complete course packages, with PDF / Markdown, isolated profiles and materials-only mode. monash semester prints one private week view of deadlines, Ed lessons and cached attendance, and can write it out as an .ics file. AI / MCP access, full-text search and optional mail and attendance integrations are also available. See the course materials guide.
  • Student Q&A bot: answers students and parents on WeChat from rules, with a model that may only quote. The checking code is its own package, quotegate.
  • Attendance Helper: a Chrome extension that finds attendance codes and submits only the classes you confirm. On the Chrome Web Store.
  • Ed Web: reads and searches an Ed forum in the browser, with no backend.

Guides for student tools are at docs.secureview.tech. Older coursework and experiments are in the project archive; their READMEs explain what was rebuilt and what is no longer deployed.
