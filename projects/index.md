This is the fuller list. The [home page](/) shows only a few projects; many others started as coursework, experiments or tools I needed for my own machines. Some are still running, while others are public, cleaned-up reconstructions of older work.

For installation, go to each project's README. For the story behind a project, see the [blog posts](/#writing). My [GitHub repositories](https://github.com/Waldo0926?tab=repositories) are the source of truth for code and maintenance status.
