关于

我是温硕勋（Shuoxun Wen），在 Monash University 读计算机科学（Algorithms and Software 方向）。

我做的东西大多是给 Monash 同学用的，也都是我自己在运行：一台 VPS，Docker、nginx、自动部署，还有一个公开的运行状态页。这个博客记录这些项目是怎么做的，以及中间出过什么问题。

项目

  • Monash Hub：课程和专业信息、选课规划、WAM 计算器、马来西亚学费、重要日期和官方学生指南，中英双语。（代码）
  • SecureView：文件在浏览器里加密的文件分享平台。我们的毕业设计，合并的 212 个 PR 里 187 个是我写的。
  • Monash Study Kit：让 Claude 和其他 MCP 客户端读你自己的 Moodle 和 Ed，课件能全文搜索。1.4 起还可以自己开远程模式，ChatGPT 和网页版 Claude 也能用；1.5 起还能接上学校邮箱和考勤，每一次发邮件、改标签或签到都要你确认。已发布到 PyPI。
  • 学生问答机器人：在微信上回答同学和家长的问题，先用规则，大模型只许摘原句。核对摘句的代码单独做成了一个包 quotegate。
  • 签到助手：Chrome 扩展，帮你找签到码，只提交你确认上过的课。已上架 Chrome 应用商店。
  • Ed Web：在浏览器里抓取和搜索 Ed 论坛，没有后端。

这些学生工具的使用指南在 docs.secureview.tech。其他项目在 GitHub。
